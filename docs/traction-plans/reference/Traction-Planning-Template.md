## Part B — Menu Picks (choose 5–8 for THIS cycle)

> Filter by ICP + stage. For each chosen activity, write a traction hypothesis, owner, and how you'll measure it. Full step-by-step is in the COMPLETE reference.

### How to choose
1. Match ICP (use the recommended lists below).
2. Match stage: **Pre-launch** → cohort building, content, waitlist mechanics. **First users** → validation/research, onboarding, community. **Scaling** → paid, partnerships, retention, distribution, monetization.
3. Don't over-commit — 5–8 active experiments per cycle is plenty.

### Recommended starting picks

**If B2B 🅱️2🅱️**
- Cold outreach to prospect list
- Recruit through founder's network
- "Why we're building this" founder post (LinkedIn)
- SEO landing page / Comparison page
- Integration co-launch
- "Invite a teammate" mechanic (⚙️, once multi-user value exists)
- G2 / Capterra presence + Privacy/Terms (when procurement shows up)

**If B2C 🅲**
- Post in niche communities
- Partner with a community leader
- Consistent posting + Community engagement (Discord)
- Waitlist with referral unlock (⚙️)
- Micro-budget ad test (Meta)
- Product Hunt launch (when there's something real)
- Trustpilot presence + Accessibility audit

**Always valuable (any ICP, once you have users)**
- 30-minute user interviews
- In-app cohort survey + Session recording review
- Weekly "what did we learn" summary
- Onboarding optimization (⚙️)
- Weekly engagement review
