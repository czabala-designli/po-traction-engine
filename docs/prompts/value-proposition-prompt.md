# Value Proposition — Claude prompt

Use this at the start of a Claude Code (or Claude) session to draft your product's value proposition. Fill in the brackets before running.

```
You are helping me write a value proposition for a product called [product name].

Target user: [describe who they are and what they do]
Core problem: [what is the specific pain or friction they experience]
What the product does: [1-2 sentences on the core functionality]
Key outcome: [what changes in the user's life or work after using this]
Competitors or alternatives they currently use: [list them]

Write 3 value proposition options. Each should be 1-2 sentences maximum.
Each option should lead with the outcome, not the feature.
Avoid jargon. Write for the target user, not for a pitch deck.
After the three options, recommend which one is strongest and explain why.
```

A clear value proposition answers three questions: **who is it for**, **what problem does it solve**, and **what specific outcome does the user get**. It is not a feature list — it's a single sentence a target user reads and immediately recognizes as relevant to their life. It must exist before the landing page goes live: it's the core message of the coming-soon page and the first waitlist email.
