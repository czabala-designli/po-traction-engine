# Skill (stub): brand-voice

> Status: first version / stub. A companion asset skill of the `traction-plan` skill.
> See `docs/traction-plans/traction-plan-skill-design.md` (option A: the planner points to companion asset skills). Elaborate later.

## Purpose

Produce a brand voice and writing-style guide for a project (tone, do's and don'ts, vocabulary, reading level, example phrasings) so every downstream asset (blog posts, emails, community posts, ASO copy) sounds consistent. Foundational, runs early. Mara flagged this as essential and as a prerequisite to any copy.

## Relationship to the traction-plan skill

- The planner points here from any foundation row that reads "define brand voice / writing style."
- This skill points back: it reads the project inputs (ICP doc, product one-liner, any existing site or voice samples) and writes a guide that every other companion asset skill then consumes.

## Inputs (to elaborate)
