A clear value proposition answers three questions: who it's for, what problem it solves, and the specific outcome the user gets. It's the core message of your waitlist page and your first email — write it *before* you build the page.

## The prompt

<a href="/starters/value-proposition-prompt.md" download="value-proposition-prompt.md"><strong>Download the value-proposition prompt</strong></a> (or <a href="/starters/value-proposition-prompt.md" target="_blank" rel="noopener">view it raw</a> in a new tab).

Then open Claude Code and say: *"Read the value-proposition-prompt.md in my download folder and let's get started."* It drafts three outcome-led options and recommends the strongest.

## Where it fits

Your value proposition feeds directly into the **[Waitlist Landing Page](/library/waitlist-landing-page)** — that template's CLAUDE.md starter asks for it during setup. Do this first, then build the page.
