Find the words your ICP actually types into Google, so blog content aims at real search demand instead of a guess. It builds on your ICP work (their real problems and language), and by default uses only free Google tools, no paid SEO account required.

## Install the skill

This play runs as a Claude Code skill. You don't have it yet, so install it once:

1. <a href="/starters/keyword-research.md" download="keyword-research.md"><strong>Download the skill</strong></a> (saves as `keyword-research.md`), or <a href="/starters/keyword-research.md" target="_blank" rel="noopener">view it raw</a>.
2. Open Claude Code and say: *"Install the keyword-research.md in my download folder as a skill."* (Claude drops it into `.claude/commands/`.)
3. Run **`/keyword-research`** and follow the 5-step session. You'll run a few quick Google searches as you go, so set aside about 15 minutes.

## What it produces

- A keyword shortlist saved to `docs/keyword-research.md`: what people type, why they're searching it, how much real demand there is, how crowded page 1 is, which theme it belongs to, and a blog post angle.
- A "Start here" list of the 3-5 best first targets to write about.
- An honest method note: this uses free signals (rising, steady, thin demand; crowded or open difficulty), not exact numbers. Google Keyword Planner or SEMrush are there as an optional upgrade, never required to finish.

## Where it fits

Run this after ICP / Persona Research, since the searches come from your audience's real problems and language. Its output feeds the Blog Section alongside Brand Voice, one gives the posts their targets, the other gives them their sound.
